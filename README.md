# Swastik Letter Portal v3 (GitHub Pages)
Upload ALL files + the `assets` folder to the repo root (replace old ones). Settings > Pages > main / root.
Preeti font: either (a) install Preeti on the computers (works automatically), or (b) put the file as assets/Preeti.ttf in the repo,
or (c) upload the .ttf in Letterheads (Head Office -> Publish) / My Letterhead (branch).
Logins: credentials.csv (unchanged).
